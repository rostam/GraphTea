Welcome to GraphTea

Draw a graph, generate one, then measure it.

 

Draw a graph

  • Click empty space to add a vertex
  • Drag from one vertex to another to add an edge
  • Drag a vertex to move it
  • Right-click a vertex or edge for its options
  • Select, then press Delete to remove

Find anything

GraphTea ships hundreds of reports, algorithms and operators. Press Ctrl+K to search them all by name instead of hunting through menus.

Measure it

With a graph on the canvas, open Reports for properties — chromatic number, diameter, spectra, topological indices — or Algorithms to watch one run step by step.
 

Handy keys:   Ctrl+K search  ·  Ctrl+O open  ·  Ctrl+S save  ·  Ctrl+Z undo  ·  Ctrl+A select all  ·  Delete remove selection
